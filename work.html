StrDA — stratified domain adaptation for scene text recognition

Scene-text models are trained on synthetic images and deployed on real photographs. When that gap is wide, existing unsupervised domain adaptation degrades. StrDA closes it in stages instead of one jump: estimate how far each unlabelled sample sits from the source domain, sort the target data into ordered strata, then self-train through them in sequence.

  • First author — method design, all experiments, and the paper. Accepted early to WACV 2025.
  • Proposed the Harmonic Domain Gap Estimator to measure out-of-distribution and domain-discriminative levels per sample.
  • State-of-the-art on STR benchmarks using no human-annotated target data.

Publication

Peer-reviewed

IEEE/CVF WACV 2025 · Early acceptance

Stratified Domain Adaptation: A Progressive Self-Training Approach for Scene Text Recognition

Kha Nhat Le, Hoang-Tuan Nguyen, Hung Tien Tran, Thanh Duc Ngo

2025 IEEE/CVF Winter Conference on Applications of Computer Vision (WACV), pp. 8990–9000 · DOI 10.1109/WACV61041.2025.00871

Unsupervised domain adaptation loses effectiveness as the gap between source and target domains widens. StrDA reframes the problem as a sequence rather than a single shift: partition the target data into ordered subsets by proximity to each domain, then self-train progressively through them so the model only ever adapts to a small change at a time.
